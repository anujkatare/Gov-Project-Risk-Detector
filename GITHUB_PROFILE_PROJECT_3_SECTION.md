## Project 3 — Predictive Construction Project Overrun Model

[![Executive dashboard](https://raw.githubusercontent.com/ND3404/predictive-construction-project-overrun-model/main/assets/executive_model_dashboard.png)](https://github.com/ND3404/predictive-construction-project-overrun-model)

**Early-Warning Classification and Regression for Cost Overruns and Schedule Delays**

A time-validated construction machine-learning case study using 2,362 synthetic project snapshots to predict future cost-overrun and schedule-delay risk from early project-controls and workflow indicators.

**Highlights**

- Cost-overrun test performance: ROC-AUC 0.899 and PR-AUC 0.774
- Schedule-delay test performance: ROC-AUC 0.756 and PR-AUC 0.524
- 40 predictors combining Project 1 controls concepts and Project 2 workflow concepts
- Red / Yellow / Green project prioritization with human-review controls
- Python, SQL, SQLite, Excel, Power BI, Tableau, explainability, and model governance

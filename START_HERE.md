## Quick summary

This repository contains a complete six-phase construction analytics and machine-learning case study using synthetic data. It predicts cost-overrun and schedule-delay risk from early project-controls and workflow indicators.

## Governance warning

Production use on real construction projects is **not authorized** by this repository. Human review, independent validation, drift monitoring, and a formal pilot would be required first.

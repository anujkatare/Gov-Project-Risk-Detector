# Ask Phase

## Project

**Predictive Construction Project Overrun Model**  
**Project code:** IP-DA-003  
**Sponsor:** In Project LLC

## Primary business question

**Which early and mid-project indicators best predict material construction cost overruns and schedule delays, and how can management prioritize intervention before the outcomes become unavoidable?**

## Target outcomes

- **Cost overrun flag:** final cost overrun is at least 10% of the original budget.
- **Schedule delay flag:** final schedule delay is at least 30 calendar days.
- **Combined overrun flag:** either the cost or schedule threshold is exceeded.
- **Magnitude targets:** final cost-overrun percentage and final schedule-delay days.

## Decision context

The model is designed for a project snapshot taken between approximately 35% and 60% planned completion. Only information available at or before the snapshot may be used as a predictor.

## Intended users

- Executive Sponsor
- Project Manager
- Project Controls Lead
- Cost Manager
- Scheduler
- Design Manager
- Change Manager
- Data Analyst

## Intended decisions

- Which projects require early management review?
- Which risk drivers should be investigated?
- Where should project-controls resources be focused?
- Which projects need cost, schedule, RFI, change, procurement, or coordination recovery plans?
- When should a model prediction be overridden by documented project context?

## Success criteria

1. Use time-based train, validation, and test periods.
2. Prevent final-outcome leakage.
3. Compare transparent baseline and nonlinear models.
4. Report discrimination, calibration, classification, and regression metrics.
5. Provide feature importance and project-level explanations.
6. Establish human review and model-governance controls.
7. Produce reproducible SQL, Python, Excel, Power BI, and Tableau deliverables.
8. Retain explicit synthetic-data disclosure.

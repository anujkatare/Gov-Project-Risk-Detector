# Dashboard Design Specification

## Story order

1. What is the model predicting?
2. How well did it perform on the future test period?
3. Which projects are predicted to be at risk?
4. Which indicators drive prediction?
5. Does performance vary by segment?
6. What human and governance controls are required?

## Number formats

- Probabilities: 0.0%
- AUC and Brier: 0.000
- Cost-overrun magnitude: 0.0%
- Schedule delay: 0 days
- Currency: $0.0M
- Counts: #,##0

## Accessibility

- Use color and status text together.
- Do not use Red/Yellow/Green without labels.
- Provide descriptive titles and alt text.
- Keep limitations visible.
